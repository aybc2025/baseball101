# בייסבول 101 — Baseball 101

Hebrew/English interactive PWA teaching baseball basics — fielding positions,
core rules (with a tap-to-try balls/strikes/outs counter), how to read a
scoreboard, and a closing quiz. Built with React + Vite + Tailwind, no
backend — progress is saved on-device only.

See `CLAUDE.md` for architecture notes and setup, or the approved spec doc
for the original mockups and decisions.

## Quick start

```
npm install
npm run dev
```
